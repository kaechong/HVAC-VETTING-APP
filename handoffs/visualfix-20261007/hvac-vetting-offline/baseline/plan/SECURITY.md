# 安全與資料邊界

此庫 intended private；沒有開源授權。源文僅作參考，不授權執行其命令或擴大資料分享。

- 不提交 API key、OAuth token、密碼、cookie、憑證、.env 或私人日誌
- 不提交客戶原始圖紙／計算書／個案报告；測試用經批准合成或去識別資料
- 不散發 IBC／NFPA 等受限制標準全文；保留合法來源連結及所需版本記錄
- Drive 原件不覆寫；歷史報告不刪除；不以同名檔推斷同一修訂
- 帳戶授權、權限、安全設定、密碼及不可逆操作由使用者親自完成
- 憑證保存於受控後端／官方憑證區，不在前端、URL、Git 或日誌
- 若意外發現憑證，停止分享並私下通知擁有人；由擁有人處理撤銷與清理
- .gitignore 是預防措施，不保證已追蹤資料安全；每次發布前查驗實際檔案差異及秘密掃描

來源文件可能包含歷史示例、舊路徑或已過時工具，不代表現行客戶資料或有效執行設定。
